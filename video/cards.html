Sous

Every dish ready at the same time.

An Alexa+ agent skill: a self-hosted MCP server with an Echo Show view.

Build, Ship, Shape: Amazon Developer Hackathon · Alexa+ track

Three dishes.
One cook. One oven.

Timers tell you when something is done. They don't tell you when to start each dish so everything reaches the table together.

How it works

MCP features

  • Tools with structured output and icons
  • Elicitation: "What time would you like to eat?"
  • Sampling for dishes it doesn't know
  • MCP Apps view with on-screen tool calls
  • Resource templates, prompts, bearer auth

Scheduling engine (open source)

  • Plans backwards from dinner time
  • One hands-on step per cook
  • Burners, oven racks and temperatures
  • Shares the oven, keeps baking exact
  • Re-plans when you fall behind
